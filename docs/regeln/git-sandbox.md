# Rules: git, commits, sandbox

Part of the agent manual (`CLAUDE.md`). Read this before your first commit in a session, after a sandbox reset and before you push. Which branch is current and what is pushed: `HANDOFF.md` → „Git-Stand".

- The tag at the end of a rule is the session that wrote it; rules written after Session 20 carry their date. **If two rules disagree, the later one wins** (date > `S20 …` > `S19` > … > `≤ S9`).

## Speicher-Limit der Sandbox: 128 MB
- **Speicher-Limit der Sandbox: 128 MB** (Angabe des Nutzers aus seiner Anzeige; 1 MB = 1 048 576 Bytes). Gezählt wird der Arbeitsordner samt `.git`. Nicht mitgezählt – und nach einem Reset weg – sind `node_modules`, `dist`, alle Ordner namens `out`, `.npm`, `.cache` und `.git/config`. **Über dem Limit geht der Stand verloren:** am 2026-11-22 war nach einem Reset der letzte lokale Commit weg – `.git` stand wieder vor dem Commit, die Dateien im Arbeitsordner waren noch da. Gemessen: mit dem Commit 130,6 MB, ohne ihn 117,3 MB – genau der Wert, den die Anzeige des Nutzers danach noch zeigte. Dass das Limit die Ursache war, ist daraus geschlossen, nicht bewiesen.
  - **Ursache der Größe:** `tools/harness/out/game.js` ist versioniert. Jedes neu gebaute Bundle landet bei `git add`, `git commit` und `git stash` als loses Objekt von 12,3 MB in `.git/objects`. Sechs davon lagen dort (vier aus Commits, zwei aus verworfenen Zwischenständen mit `git stash`) – `.git` war 105,8 MB groß.
  - **Regel: nach jedem Commit `git gc --prune=now`** (≈ 5 s). Gepackt kostet eine weitere Bundle-Version nur Kilobytes (gemessen: 0,2 – 177 kB; alle 28 älteren Versionen zusammen 0,4 MB). Prüfen: `git count-objects -vH` – `size` (lose Objekte) muss `0 bytes` sein.
  - **Kein `git stash`, solange ein neu gebautes Bundle im Arbeitsordner liegt.** Für Vergleiche mit einem älteren Stand: `git show <Commit>:<Pfad>` oder `git archive <Commit> | tar -x -C /var/tmp/<Ordner>`.
  - **`npm run save` ist abgeschaltet** (2026-11-22, Entscheidung des Nutzers: „erstmal"). `tools/save.sh` gibt gleich am Anfang eine Meldung aus und endet mit Exit-Code 1 – nichts wird committet, nichts geschrieben (geprüft: `HEAD`, `git status` und der Arbeitsordner bleiben gleich). Grund: das Skript legte drei Kopien von `.git` an (gemessen: 123 MB zusammen). **Wieder einschalten nur auf Wunsch des Nutzers:** den markierten Block am Anfang von `tools/save.sh` löschen (bis zur Zeile „end of switch"); der Rest des Skripts ist unverändert. `package.json` wurde dafür nicht angefasst. Offen: endgültig entfernen oder wieder einschalten.
  - `npm run restore-git` ist **nicht** abgeschaltet: fehlt `.git`, holt es den Ordner von GitHub – seit dem 2026-11-22 den Zweig `dev` (vorher fest `B`; in einem Ordner ohne `.git` getestet). Nie gepushte Commits sind dann weg, lokale Änderungen erscheinen als geändert.
  - **Ganz neu packen** (am 2026-11-22 einmal gemacht, 38,7 → 33,2 MB): `git -c pack.threads=1 -c pack.windowMemory=500m repack -a -d -f --window=50 --depth=50`, danach `git fsck --full`. Größere Fenster bringen nichts mehr (33,1 MB).
  - **Stand nach dem Aufräumen (2026-11-22): rund 48 MB.** `.git` 33 MB (neuestes Bundle 11,9 · Texturen 11,2 · die gelöschte Text-Sicherung in der Historie 7,8 · alles andere 2,4), `src` 12,4 MB (davon Texturen 11,2), `.archiv` 1,3 MB.
  - **Reserve, falls es wieder eng wird** (nicht gemacht): die lokale Historie kürzen (`git fetch --depth 1`) bringt 8,6 MB – fast nur die alte Text-Sicherung, die ganze übrige Historie wiegt 0,8 MB. Zusätzlich die Harness-Bundles aus Git nehmen bringt weitere 12,4 MB. Die alte Historie bliebe auf GitHub.

## After a sandbox reset
- **Sandbox persistence:** if `.git` or `src/assets/menu-bg.jpg` vanished after a reset, restore via `git clone --branch dev https://github.com/Cr0nFixXx/podracer.git /tmp/rc && cp -r /tmp/rc/.git . && mkdir -p src/assets && cp -n /tmp/rc/src/assets/menu-bg.jpg src/assets/` (working tree stays, shows as modified vs. `dev`; `dev` is the work branch since 2026-11-22, before that `B`). *(2026-11-22)*
- **Nach einem Sandbox-Reset** fehlt `.git/config`: `git config core.fileMode false` (sonst erscheinen alle Dateien als geändert – nur Dateirechte), `git remote add origin https://github.com/Cr0nFixXx/podracer.git`, `git checkout -- tools/harness/out`.
- Fehlt nach einem Reset doch einmal ein Commit: die Schritte aus dem Punkt darüber, `npm ci`, beide Harness-Bundles neu bauen, `npm run check`, neu committen. Ein nur lokaler Commit ist erst sicher, wenn er gepusht ist – dem Nutzer sagen, wenn einer nur lokal liegt.

## Sandbox: 2 GB RAM, software GL
- **Sandbox with 2 GB RAM and software GL:** never run the headless browser together with `tsc`, the sim or esbuild; one track per browser run (two tracks with 1024 px photo sets exhaust the memory); wrap every run in `timeout`; `/tmp` is a RAM disk – delete old screenshots and `/tmp/puppeteer_dev_chrome_profile-*`; `pkill` patterns need a character class (`"pshot[.]mjs"`), otherwise they kill the calling shell. After a reset: `git config core.fileMode false`. *(S20 Strecken)*
